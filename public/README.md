# Portfolio Assets and Data

## Overview
This portfolio has been updated with:
- Enhanced navigation with smooth scrolling
- Animated Hero section using Framer Motion
- Local image assets (to be added)
- Updated content based on CV information

## Image Assets Required
The following images need to be added to `/public/images/`:
- Profile images for Hero and About sections
- Project screenshots
- Certificate images

## Navigation
- All navigation now properly handles both same-page and cross-page anchor links
- Clicking on any navigation item from any page will navigate to the correct section
- Smooth scrolling is implemented for better user experience

## Content Structure
- Hero: Personal introduction and call-to-action
- About: Professional background and experience
- Skills: Technical skills and tools
- Projects: Portfolio of work with detailed descriptions
- Certificates: Professional certifications
- Contact: Contact information and form

## Future Updates
To completely customize this portfolio:
1. Add your real images to `/public/images/`
2. Replace placeholder content with information from your CVs
3. Update your contact information
4. Add real project links and GitHub repositories
5. Include links to your resume/CV PDFs
